CUIDADO CON EL HISTORIAL

Reset

Los modos determinan qué partes del estado del repositorio se actualizan.

!

Atención: --hard puede descartar cambios locales. Verifica el estado del repositorio antes de ejecutarlo.

SOFT

Conserva los cambios preparados

Mueve HEAD; mantiene el staging area y el working directory.

git reset --soft abc1234
MIXED

Reinicia el staging area

Mueve HEAD y limpia el staging area, sin descartar los cambios del working directory. Es el modo predeterminado.

git reset --mixed abc1234
HARD

Descarta cambios locales

Actualiza HEAD, staging y working directory al commit indicado.

git reset --hard abc1234
git reset --hard HEAD~1
git reset --hard HEAD@{1}

MENSAJE.git/index.lock: File exists

Git detecta un archivo de bloqueo. Primero confirma que no haya otro proceso Git ejecutándose.

COMANDO · SOLO SI NO HAY OTRO PROCESO ACTIVO
rm -f .git/index.lock
